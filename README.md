# Conference Registration Form

## Project Description

This project is a Conference Registration Form developed using HTML5 and CSS3.

It allows students, researchers, faculty members, and professionals to enter their personal information and conference details.

## Technologies Used

- HTML5
- CSS3

## Features

- Personal Information
- Email and Phone Number
- College Name and Department
- Participation Type
- Gender Selection
- Conference Details
- Preferred Session
- Accommodation Required
- Additional Comments
- Submit and Reset Buttons
- Form Validation
- Attractive CSS Design
